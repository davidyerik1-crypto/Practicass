DOM


El DOM (Document Object Model) es una interfaz de programacion que representa la estructura de un documento Modelo de Objetos del documento.
Cuando el navegador web lee y analiza una página HTML la convierte en un modelo en memoria organizado como un árbol jerárquico de nodos.




Ejemplo:

Aqui estamos dando una 'id' a una etiqueta 'p' para despues con un script seleccionarlo con .getElemntByID y asi poder editarlo
en este caso editarlo para ponerle un estilo, un color amarillo a las letras.
